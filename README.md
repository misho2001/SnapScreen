# SnapScreen
This project represents a Java project named sacdeli, which is primarily designed to implement screen capture functionality.

Project Content and Structure:
Project Configuration (.idea/, .gitignore): Includes IntelliJ IDEA workspace configuration files and Git settings.

Source / Compiled Code (classes/):

Contains compiled Java classes (ScreenCaptureApp.class and ScreenCaptureApp$WindowInfo.class) responsible for screen recording/capturing and processing window information.

Output Packages and Execution (output/):

Includes the application distribution package (such as .jar files, configurations, and Java Runtime Environment libraries), allowing the program to run independently (using Windows system libraries like api-ms-win-core-...dll).

Technologies Used:
Language: Java

Platform / Tools: IntelliJ IDEA, JavaFX or Swing (for screen and window management), and Java Packaging (jpackage) for creating the application distribution.
